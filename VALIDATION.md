# Проверки 2026-09-14

Среда: macOS arm64, Go toolchain 1.26.8. Живой Linux-сервер и работающая Linux VM/container в этой сессии не предоставлены.

Набор Go-тестов включает дополнительные подслучаи и две fuzz-цели. Тесты проверяют случайные двоичные payload, одновременную передачу SIP в обе стороны, неправильный секрет, повреждённые/обрезанные SIP-сообщения, недопустимые длины пакетов, перестановку/дубликаты/просрочку фрагментов, ограничение сборки, отклонение IP-пакетов с чужим адресом источника, закрытие обеих сторон bridge и сохранение исходных DNS-настроек/маршрута к серверу.

Добавлены проверки остановки: отмена во время изменения сети с последующим откатом, запрет новых изменений после отмены, возврат ошибки при неудачном откате и повтор только неудавшихся операций. Отдельный процесс с реальным обработчиком CLI получает SIGINT/SIGTERM для SIP, SIP/TLS, WebRTC и REALITY при открытом незавершённом соединении; проверяются завершение с кодом 0, сообщение `shutdown complete` и возможность повторно занять порт. Эти процессные проверки используют echo-режим без TUN; системный откат проверяется моделированием команд, а не изменением сети macOS.

Обнаруженная тестом взаимная блокировка SIP при одновременной передаче исправлена: ответы SIP отправляются отдельным обработчиком, чтение входящего соединения не ждёт записи ответа.

Захват pcap и анализ классификации трафика сетевым оборудованием ещё не выполнялись. Успешное соединение Pion подтверждает работу реализации ICE/DTLS/SRTP и двустороннюю передачу payload, но не неотличимость от видеозвонка. Измерения CLI на loopback не являются оценкой максимальной скорости или поведения реальной сети.

Интерфейсы и маршруты этой macOS-машины в процессе разработки не изменялись. Команды для проверки реального выхода через шлюз находятся в README и `scripts/netns-test.sh`.
